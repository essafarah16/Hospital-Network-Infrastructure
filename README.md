# Hospital-Network-Infrastructure
Design and configuration of a three-floor hospital network using Cisco Packet Tracer, including VLANs, DHCP, wireless networking, OSPF, RIPv2, and route redistribution.
## Network Features

- Multi-floor hospital network
- VLAN configuration
- Wireless LAN Controller (WLC)
- DHCP configuration
- Wireless connectivity
- RIP Version 2 routing
- OSPF routing
- RIP and OSPF redistribution
- Routing verification
- Network connectivity testing using Ping

## Network Devices

- 6 PCs
- 2 Laptops
- 1 Tablet
- 4 IP Printers
- 4 Cisco Switches
- 3 Cisco Routers
- 1 Wireless LAN Controller (WLC)
- 1 Lightweight Access Point
- 1 Server

## VLANs

- VLAN 10 – Pharma
- VLAN 20 – Clinics
- VLAN 30 – ER

## Tools

- Cisco Packet Tracer
